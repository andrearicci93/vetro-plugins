Connect Vetro ✓ connected

Reads Vetro’s MQTT settings, rules and remote interception, and says what is missing.
    1. Point Vetro's MQTT link at this Shard. In Vetro's MQTT page: broker 127.0.0.1, port 1883, no user name or password, TLS off. Keep the topic prefix vetro, enable the connection and save. The badge at the top turns green within half a minute.
    2. Find your remote's key codes. In Vetro's Remote page, choose the remote, select Start listening and press Volume up, Volume down and Mute. Note the code shown for each, then select Stop listening: while Vetro listens, no rule runs.
    3. Add one rule per key (MQTT page › Rules). Change Trigger type from “MQTT message” to Physical key, enter the code from step 2, leave the payload blank, choose the action Publish MQTT message and enter the destination topic:
      Remote keyDestination topic
      Volume up
      Volume down
      Mute

      Also available: and . The payload does not matter.

    4. In the Remote page, choose your remote in the device menu (not “Detect automatically”, which only listens), then turn on Remote interception. Vetro intercepts one remote at a time: on a 2022 The Frame the infrared remote is “wt61p807 rc device”. From then on those keys go to Sonos instead of the TV: the TV’s own volume no longer changes. Then press Check Vetro setup above.

    If a key press reaches Vetro while this Shard is off, Vetro gives the keys back to the TV for a minute, then tries again.
