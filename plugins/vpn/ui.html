NordVPN access token

Create one in Nord Account → NordVPN → Set up NordVPN manually → Generate new token. It is kept on the TV only (/opt/nordtv/token) and never shown again.

WireGuard profiles

A profile is a WireGuard config file (.conf) from your provider's website (Mullvad, Proton VPN, Surfshark, IVPN, AirVPN…) or from your own server (wg-easy, a router, a NAS). One server per profile; IPv4 only.

Add a profile

AllowedIPs = 0.0.0.0/0: everything goes through the VPN, DNS included (the config's DNS, or Quad9 if it has none), and the kill switch applies. Narrower AllowedIPs (split): only those addresses go through the VPN, the rest uses your normal connection, and the kill switch is not used. Your home network stays reachable either way. The config, keys included, is kept on the TV only (/opt/nordtv/profiles) and never shown again; saving a name again replaces it.

Reset

Turns the VPN off and deletes the NordVPN token, every WireGuard profile, the settings and the log from the TV, as after a fresh install. The VPN program stays.
