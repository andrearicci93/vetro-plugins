SSH server

A real SSH endpoint on the TV, in pure JavaScript. Status: …

What you can do

ssh -p 2222 root@TV-IPinteractive root line-shell via Vetro's agent — each command runs as root, cd is remembered. No PTY: no top/vi/less (use top -b -n1)
ssh -p 2222 root@TV-IP 'id'runs a single command as root via the agent
sftp -P 2222 x@TV-IPscp/sftp file transfer as the owner (uid 5001) — owner-readable files

The username is ignored (you authenticate with your key). The interactive shell and single commands run as root through Vetro's agent; file transfer runs in-process as the owner (uid 5001), because the TV's sandbox blocks this process from executing binaries. Keep this on a trusted LAN — never expose the port to the Internet.

Authorized keys

Paste the public ed25519 key(s) allowed to log in (one per line). Generate one with ssh-keygen -t ed25519 and paste the .pub. Keys are stored in this Shard, not in ~/.ssh. Applies to new connections at once.
