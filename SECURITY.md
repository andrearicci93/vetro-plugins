# Reporting a problem with a plugin

If a plugin in this list is malicious, steals data or can damage a TV, please report it privately through
[GitHub private vulnerability reporting](https://github.com/andrearicci93/vetro-plugins/security/advisories/new)
rather than a public issue. Include the plugin id, the version and what it does.

A confirmed report is handled by removing the entry from `index.json`, as described in
[CONTRIBUTING.md](CONTRIBUTING.md). For problems in Vetro itself see its
[SECURITY.md](https://github.com/andrearicci93/vetro/blob/main/SECURITY.md).
